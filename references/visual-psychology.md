# Visual Psychology

## Purpose
Understand how humans perceive and respond to visuals — attention, emotion, cognition, memory, and the psychological principles that make design effective or off-putting.

## Core knowledge
- **Attention:** saliency (visual pop-out), contrast (isolated elements draw eye), motion (moving elements attract), faces (humans notice faces first), text (readable content draws attention); attention is limited — compete for it deliberately.
- **Perception principles (Gestalt):** proximity (near = group), similarity (same = group), continuity (follow lines/curves), closure (complete incomplete shapes), figure-ground (separate subject from background), common fate (move together = group).
- **Cognitive load:** every element costs mental effort; cluttered designs exhaust viewers; progressive disclosure (show less, reveal more); chunking (group related items); Hick's Law (more choices = slower decisions).
- **Emotional response:** colors trigger emotions (red = arousal, blue = calm); curves vs. angles (curves = friendly, angles = aggressive); faces with direct gaze = engagement; symmetry = stability, asymmetry = energy.
- **Memory and recognition:** distinctive shapes remembered better; repetition builds familiarity; peak-end rule (remember peak moment + ending); serial position (first and last items remembered most).
- **Visual hierarchy:** size (bigger = more important), color (saturated/brighter = attention), position (top-left in Western reading, center in some cultures), contrast (isolated = important), whitespace (empty space = emphasis).
- **Aesthetic response:** processing fluency (easy-to-process = beautiful), mere exposure effect (familiar = liked), contrast effects (context changes perception), peak-end rule in experiences.
- **Trust and credibility:** professional design increases trust; cluttered/dated design decreases it; consistency builds trust; errors (typos, broken images) destroy it.

## Evaluation criteria / rules
- Evaluate designs on: attention guidance (does eye go where intended?), cognitive load (is it overwhelming?), emotional tone (does it match goal?), memory hooks (is it memorable?), trust signals (does it look professional?).
- Check Gestalt principles: are related elements grouped? Are separate elements distinct? Is there visual confusion?
- Assess visual hierarchy: can viewer identify primary/secondary/tertiary elements in 2 seconds?
- Consider user context: stressed users need simpler designs; exploratory users tolerate complexity; expert users want efficiency.
- Flag psychological errors: attention competition (everything screams), cognitive overload (too many choices), emotional mismatch (playful design for serious context), trust violations (unprofessional details).
- For persuasion: use social proof, scarcity, authority, reciprocity (Cialdini's principles) visually — but ethically.

## Confidence & limits
- High confidence: obvious Gestalt violations, cognitive overload (cluttered), attention failures (no clear focal point).
- Medium: "feels trustworthy," "looks professional," emotional tone assessment.
- Cannot assert: individual user psychology, cultural variations in perception, long-term behavioral effects without testing.
- Always consider: psychological principles are probabilistic, not deterministic; individual differences matter.
