# Feng Shui Review

## When to use
Use when the user explicitly requests Feng Shui assessment, or when reviewing residential/commercial interiors where spatial harmony principles apply. Treat as a cultural/design lens, not a scientific claim.

## Inputs required
- One or more images of the space (interior preferred; floor plan helpful)
- Optional: compass orientation, occupants' goals (wealth, health, relationships, career)
- Optional: user tradition preference (Ba Zhai, Flying Stars, Form School, or general Five Elements)

## Steps
1. **Establish the lens.** State which Feng Shui approach will be used and its epistemic status: symbolic design heuristics, not measurable physics. Keep claims framed as design guidance.
2. **Map the Five Elements.** Inventory visible elements: Wood (plants, wood, green), Fire (red, candles, electronics), Earth (earth tones, ceramics, square stability), Metal (white/gray, metal, round forms), Water (blue/black, mirrors, fountains, glass). Note imbalances — all-Earth heaviness or total absence of Water.
3. **Assess Form School cues** (if applicable): main entrance visibility and clarity, unobstructed path from door, command position for key furniture (bed/desks facing door but not directly aligned), sharp corners aimed at occupants, clutter concentration.
4. **Assess Ba Zhai / directional cues** (if orientation given): which directions matter for stated goals; note where the space's "power spots" fall relative to doors/windows. If no orientation data, restrict to non-directional principles and say so.
5. **Clutter and energy-flow (Qi) read.** Identify blocked pathways, dead-end corners, excessive visual noise, and areas of stagnation vs. flow. Note mirrors facing beds/doors (common red flag) and overloaded entryways.
6. **Color and material harmony.** Evaluate palette against Five Elements balance; flag overwhelming single-element dominance.
7. **Cross-check with function.** Feng Shui recommendations must not defeat practical function (e.g., never recommend blocking ventilation or emergency egress). Flag any conflict explicitly.
8. **Deliver as design suggestions**, not prescriptions: "consider," "a common approach is," never "must" or fortune-telling claims.

## Output format
```
APPROACH: <Ba Zhai / Flying Stars / Form / Elements>
ELEMENTS MAP: <Wood/Fire/Earth/Metal/Water inventory>
STRENGTHS: <aligned features>
CONCERNS: <imbalances and blocked areas>
SUGGESTIONS: <actionable, function-safe changes>
CAVEATS: <orientation missing, tradition preference, etc.>
```

## Confidence handling
- HIGH: clear interior photos, orientation known, user specifies tradition.
- MEDIUM: photos only, no orientation — restrict to Form School and Elements; mark directional analysis as not assessable.
- LOW: exterior-only or ambiguous spaces — provide only general principles; state that reliable assessment needs floor plan and orientation.
