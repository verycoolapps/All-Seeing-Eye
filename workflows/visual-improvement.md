# Visual Improvement

## When to use
Use when the user wants to improve an existing visual — photo, render, design, space, or asset — and needs concrete, prioritized change recommendations rather than just critique.

## Inputs required
- One or more images of the current state
- Optional: target state (reference image, style goal, functional requirement)
- Optional: constraints (budget, time, tools available, cannot change structure)

## Steps
1. **Diagnose before prescribing.** Complete a full analyze-image pass first. Never recommend fixes for problems you haven't identified.
2. **Prioritize by impact.** For each identified weakness, estimate: (a) how much it hurts the overall impression, (b) how feasible the fix is. Use priority-system.md to rank.
3. **Generate the improvement list.** For each weakness, produce the full improvement record: existing condition → weakness → root cause → recommended change → expected benefit → trade-off → priority level.
4. **Separate quick wins from investments.** Group recommendations: "fix today" (crop, exposure, declutter, color adjust), "this week" (repaint, rearrange, replace material), "this project" (renovation, reshoot, redesign).
5. **Provide concrete instructions.** For each recommendation, be specific: not "improve lighting" but "add a warm 3000K source at 45° to the left of the subject" or "shift exposure +0.7 and recover highlights."
6. **Sequence the changes.** Order recommendations so early fixes don't waste effort on changes that later steps will alter (e.g., fix composition before color grading).
7. **Flag what NOT to change.** List elements that are working and should be preserved — improvement often destroys good things.
8. **Estimate outcome.** State expected improvement honestly: some fixes are transformative, others marginal. Never promise perfection.

## Output format
```
CURRENT STATE: <one-line diagnosis>
QUICK WINS: <numbered, concrete>
MEDIUM-TERM: <numbered>
LONG-TERM: <numbered>
PRESERVE: <elements to keep>
EXPECTED OUTCOME: <realistic description>
```

## Confidence handling
- HIGH: clear image, obvious fixes, no structural unknowns.
- MEDIUM: image partially obscured or context incomplete — mark recommendations as conditional.
- LOW: cannot see the space/subject fully (single angle, blurry) — provide only general guidance and state what additional views are needed for specific recommendations.
