# ALL SEEING EYE VISUAL REPORT

The standard 10-section report template for all visual reviews. Fill every section; if a section has nothing to say, write "No significant issues identified" — never leave blank.

---

## 1. FIRST IMPRESSION
One paragraph: what hits you first, what the image/space communicates instantly, and whether that first read is accurate or misleading. Be honest about gut reaction before analysis.

## 2. VISUAL IDENTITY
What aesthetic identity does this project have? Describe the style in 3–5 adjectives (e.g., "warm minimalist industrial"). Note whether the identity is coherent or confused. If no clear identity exists, say so.

## 3. WHAT WORKS
Bullet list of strengths — specific, not generic. "The entry sequence creates anticipation" not "the design is nice." Minimum 3 items; fewer means deeper problems.

## 4. WHAT DOESN'T WORK
Bullet list of weaknesses ordered by severity. For each: what it is, where it is, why it hurts. This section feeds directly into the priority matrix.

## 5. PROFESSIONAL CRITIQUE
The expert-level assessment. What would a senior architect/designer/photographer say? Technical accuracy, craft quality, conceptual strength. This is where you distinguish surface issues from structural ones.

## 6. AESTHETIC EVALUATION
The 10-dimension score table (visual-scoring.md). Include all scores, mark N/A where applicable, and add a one-line interpretation of the overall pattern (e.g., "strong composition but weak material quality").

## 7. IMPROVEMENT OPPORTUNITIES
The prioritized list from visual-improvement.md / priority-system.md. Group by Quick Wins / Medium-Term / Long-Term. Each item: existing condition → weakness → root cause → change → benefit → trade-off → priority.

## 8. PRIORITY MATRIX
The decision-matrix.md output: weighted scores for each option evaluated, decision level (1–4), and the MY RECOMMENDATION statement. If only one option exists, state whether it passes the approval threshold.

## 9. FINAL VERDICT
One of:
- **APPROVE** — professional quality, ready for use.
- **APPROVE WITH CONDITIONS** — usable after listed fixes.
- **REVISION REQUIRED** — significant work needed before approval.
- **REJECT** — fundamental problems; start over or choose alternative.

Follow with one sentence of justification.

## 10. NEXT STEP
The single most important action to take. Not a list — one thing. "Reshoot with warm fill light" or "Replace the laminate flooring in the entry" — specific and immediately actionable.

---

## Report Footer
Reviewer / Date / Confidence / Assumptions / Limitations — one line each.
